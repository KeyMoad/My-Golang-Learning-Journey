
# My Golang Learning Journey

A small repository to store my Go projects as I progress through my learning journey.

---

## Overview

This repository contains small, focused Go programs that I’m writing while learning the language.  
Each folder represents a core concept in Go and usually contains one or more example programs.

The goal of this repo is to:

- Build a solid foundation in Go basics
- Practice writing clean, idiomatic Go code
- Track my progress as I learn new concepts

---

## Project Structure

Each numbered folder corresponds to a learning module:

```text
My-Golang-Learning-Journey/
├── 1. Hello World
├── 2. Data Types
├── 3. Variables
├── 4. Constants
├── 5. Operators
├── 6. Control Flow
├── 7. Functions
├── README.md
└── .gitignore
````

> As I progress, I’ll keep adding more folders for topics like arrays, slices, maps, structs, methods, interfaces, concurrency, and more.

## Getting Started

### Prerequisites

* [Go](https://go.dev/dl/) installed (any fairly recent version should work, e.g. Go 1.21+)
* A terminal / command prompt
* (Optional) An editor like VS Code, GoLand, or any editor with Go support

You can verify your Go installation with:

```bash
go version
```

### Clone the repository

```bash
git clone https://github.com/KeyMoad/My-Golang-Learning-Journey.git
cd My-Golang-Learning-Journey
```

---

## Running the Examples

Each module is contained in its own directory.
To run a specific example:

```bash
cd "1. Hello World"
go run main.go
```

Or for another topic, for example:

```bash
cd "6. Control Flow"
go run main.go
```

> Note: The actual file names may vary (for example `main.go` or other filenames).
> Just replace `main.go` with the appropriate file name if needed.
